# 8-Week-SQL-Challenge-by-Danny-Ma

This repository contains SQL solutions and documentation for the **8 Week SQL Challenge**.  
The challenge is designed to strengthen SQL skills through practical, real-world case studies over an eight-week period.

---

## 📌 About the Challenge

The **8 Week SQL Challenge** focuses on hands-on SQL practice using realistic datasets and business scenarios.  
It helps build a strong foundation in SQL while gradually introducing more advanced concepts commonly used in data analysis roles.

Key objectives:
- Practice writing clean and efficient SQL queries
- Understand relational database concepts
- Apply SQL to real-world analytical problems
- Build a structured SQL portfolio

Official challenge source:  
👉 https://8weeksqlchallenge.com/
